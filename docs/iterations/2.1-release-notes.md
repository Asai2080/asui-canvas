# ASUI Canvas 2.1

2.1 focuses on keeping the existing 2.0 image workflow stable while adding a node-based generation layer for image, image-to-image, image-to-video, cutout service control, and local Codex task handoff.

## Highlights

- Added contextual prompt composer that follows the selected canvas node.
- Added reference upload support with image/video type detection.
- Added image-to-image generation from uploaded reference images and prompt text.
- Added video node creation from image nodes, with connected data-flow lines.
- Added video generation settings for duration, quality, model, and canvas size.
- Added separate image and video API configuration tabs.
- Added canvas-wide generation state overlay and transient toast errors.
- Added BiRefNet HR cutout service controls.
- Added local Codex task queue and ASUI task-card bridge path.

## Safety Notes

- API keys are session-only and are not written into the repository.
- Generated assets, local task queues, and canvas caches are ignored by git.
- Existing 2.0 image generation, annotation edit, multi-annotation edit, cutout, and canvas size flows are preserved.
