# ASUI Canvas 2.0

发布日期：2026-06-27

## 版本定位

2.0 版本把无限画布从单点生图工具推进到可连续创作的 AI 图片工作台：支持画布尺寸实时调整、多标注合并改图、Codex 任务交接，以及基于 BiRefNet HR 的圈选区域主体抠图。

## 新增能力

- 新增画布尺寸浮层，支持 1:1、2:3、3:4、9:16、3:2、16:9、A4、网页和自定义尺寸。
- 支持在画布上直接修改宽高，选中尺寸后画布实时变化。
- 支持单个标注生成，也支持多个标注统一理解后合并生成一张新版本。
- 新增标注理解层，会在生成前把圈选、文字和箭头整合成明确编辑任务。
- 新增“交给 Codex”任务交接入口，写入任务队列并保留画布上下文。
- 新增 BiRefNet HR 抠图能力，按用户圈选区域裁剪后，只抠该区域内的主体。
- 新增右侧面板一键启动/关闭抠图服务，默认服务地址为 `http://127.0.0.1:7861`。
- 新增抠图服务后端接口和本地 FastAPI 服务，支持透明 PNG 返回。

## 体验优化

- 顶部工具条按 Figma 样式重新收紧，去掉不必要的 AI 标注入口。
- 右侧 AI 创作面板精简状态区，提示词输入框固定高度并支持滚动。
- 调整画布字体，内置平方乔木体资源。
- 优化尺寸下拉菜单样式，去掉多余阴影并缩小浮层。
- 改进图片生成失败、安全拒绝、服务未启动等错误提示。

## 修复问题

- 修复生成图二次标注后无法按新标注继续生成的问题。
- 修复多个标注合并时只生效一个标注的问题。
- 修复抠图请求字段不一致导致“缺少圈选区域图片”的问题。
- 修复 BiRefNet HR 首次启动缺少依赖导致 500 的问题。
- 修复本地 API 配置变更后右侧面板状态不同步的问题。

## 技术说明

- BiRefNet HR 服务依赖 Python 3、FastAPI、PyTorch、Torchvision、Transformers、Kornia、Timm。
- 首次启动或首次抠图会加载模型，可能明显较慢；后续请求会复用已加载服务。
- 抠图服务由画布启动时可在右侧面板关闭；外部服务地址仍可通过 `BIREFNET_SERVICE_URL` 覆盖。
