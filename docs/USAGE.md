# 使用说明

## 1. 启动项目

日常使用不需要运行终端命令：

1. macOS：双击项目根目录的 `Start ASUI Canvas.command`。
2. Windows：双击项目根目录的 `Start ASUI Canvas.bat`。
3. 启动器会自动安装依赖、创建默认 `.env.local`，并在浏览器打开画布。

默认地址为 `http://localhost:3001`；该端口被占用时，启动器会自动使用下一个可用端口。首次只需保证电脑已安装 Node.js 18+；不需要手动安装项目依赖或配置环境变量。

## 2. 创建生图节点

1. 点击顶部「新建生图节点」。
2. 画布会创建一个空白图片占位节点并自动选中。
3. 在右侧「画幅尺寸」中输入宽度和高度。
4. 按 Enter 或点击「应用尺寸」。

尺寸值以画布逻辑像素表示。实际模型不支持任意宽高比时，服务端会选择最接近的受支持比例。

## 3. 生成图片

1. 保持图片占位节点处于选中状态。
2. 在「图片提示词」中描述主体、风格、构图、光线和用途。
3. 点击「Fill Image Holder」。
4. 生成中占位节点会保留，完成后图片会被填入节点。

如果未配置 API，系统会使用本地演示生成器，用于体验画布流程。

## 4. 配置图像模型

1. 点击顶部左侧的「阿水画布」。
2. 填写 Base URL，例如 `https://api.openai.com/v1` 或 `https://openrouter.ai/api/v1`。
3. 填写 API Key。
4. 填写可用的图像生成模型名称。
5. 点击「保存配置」。

API Key 只存放于当前标签页的 `sessionStorage`。需要立即移除时，重新打开 API 配置并点击「清除 API Key」。

## 5. 直接在图片上批注改图

1. 选中一张已生成图片。
2. 点击顶部「AI 标注」。
3. 在图片上需要修改的位置点击，输入简洁、局部化的要求，例如「将这只杯子改成磨砂黑，其他不变」。
4. 选中批注文字后，其旁边会出现「生成」按钮。
5. 点击「生成」。

系统会同时传入原图与批注要求，并在新的画布位置创建结果。原图会保留，方便前后对比。

## 6. 画布操作

- 滚轮或触控板：平移与缩放。
- 选择工具：移动、缩放、复制或删除节点。
- 文字、箭头、画笔、图形：可用于辅助说明修改意图。
- 画布状态会在本地浏览器中保存。

## 7. 常见问题

### 点击生成后使用了演示图

检查 API 配置中的 Base URL 和 API Key 是否同时存在。关闭标签页会清除会话 Key，需要重新配置。

### 模型报错不支持宽高比

请使用模型支持的比例。OpenRouter 路由会自动在常用比例中选择最接近项。

### 局部修改重画了整张图

使用明确的局部指令，同时写明「其他区域保持不变」。不同图像模型的局部保真能力不同。

### 画布加载停在准备状态

确认启动器仍在运行，并使用启动器显示的 `http://localhost:<端口>` 地址访问。
